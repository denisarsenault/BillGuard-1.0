# BillGuard — Business & Go-to-Market Documents

Source HTML for the BillGuard strategy set. Each file is a self-contained page
(open in a browser, or re-publish as a Claude artifact). Shared visual system:
Fraunces / IBM Plex, with a distinct accent per document.

| File | What it is | Accent |
|------|-----------|--------|
| `launch-plan.html` | Launch & go-to-market master plan — product gaps, verticals, bootstrapped GTM, app→live walkthrough, pitfalls | Teal |
| `investor-plan.html` | Angel-round memorandum — the raise, market, model, milestones, finding & closing angels | Gold |
| `growth-playbook.html` | Growth & distribution playbook — ASO, programmatic SEO, content, community, PR, paid, referral, 90-day calendar | Magenta |

## Notes before sharing externally
- **Name:** "BillGuard" was a well-known bill-monitoring app acquired by Prosper
  Marketplace. Clear the trademark or adopt a clean brand (e.g. Guardia) before
  building brand equity.
- **Stats:** every market figure (~100M with medical debt, $200B+, "most bills
  have errors") is a widely-cited anchor marked *verify* — source precisely
  (KFF, CFPB, Census, CMS) before any investor meeting.
- **Raise terms:** $250–500K on a post-money SAFE, ~18-month runway are working
  assumptions, not fixed terms.
- **Contact:** the teaser and deck use denis2@me.com — swap for a company address
  if desired.
